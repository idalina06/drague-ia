RIZZ GENERATOR HARD MODE — installation Mac

1) Décompresse ce ZIP.
2) Ouvre Terminal et tape : cd ~/Desktop/rizz-site-complet
   (si le dossier est ailleurs, adapte le chemin)
3) Tape : python3 -m pip install -r requirements.txt
4) Tape : python3 app.py
5) Ouvre Safari à l’adresse http://127.0.0.1:5000

Le dossier doit garder app.py, phrases.json, requirements.txt, le dossier templates et le dossier static. L’image de fond est déjà placée dans static/fond-rizz.png.
Pour arrêter le site, reviens au Terminal et fais Ctrl+C.
